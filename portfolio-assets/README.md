# Portfolio visuals

AI-generated concept artwork produced with the built-in image generation tool.
These images illustrate the implemented preparation/inspection features; they
are not application screenshots or evidence of automatic ball tracking.

- sports-replay-cover.png: primary portfolio project cover with a laptop mockup.
- sports-replay-features.png: supporting case-study visual for table calibration,
  background frame inspection, cancellation, clearing, and local processing.
- prompts.md: complete generation prompts for both assets.

Use the cover as the project thumbnail/hero, and the feature image inside the
case study. Preserve the concept labels when presenting these images. Pair them
with actual screenshots when demonstrating the working application.

Both scenes are original generated table tennis illustrations. No uploaded
video, extracted frame, or Getty Images preview was sent to the image generator.
The concepts do not claim implemented trajectories, bounce detection, rallies,
3D reconstruction, accuracy percentages, or calibrated physical measurements.
